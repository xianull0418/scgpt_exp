# scGPT 通用微调流程
## 1. 数据准备
此阶段的目的是收集和初步组织用于微调的数据。
- **输入数据格式**:
    - 通常，单细胞数据以`AnnData`对象 (`.h5ad` 文件) 的形式存在，其中包含基因表达矩阵、细胞元数据和基因元数据。
    - 也可能直接是计数矩阵 (cells × genes) 和相应的细胞注释文件。
- **核心数据**:
    - **基因表达数据**: 每个细胞中基因的表达水平。这可以是原始计数、TPM、FPKM 或其他标准化值。
    - **细胞标签/目标变量**: 对于有监督的微调任务（如细胞类型注释），需要提供每个细胞的真实标签。例如，在细胞注释任务中，这是 `adata.obs["celltype"]`。对于其他任务，可能是扰动标签、批次信息或连续的表型值。
- **基因词汇表 (Gene Vocabulary)**:
    - scGPT 通常在特定的基因集上进行预训练。因此，你需要获取预训练时使用的基因词汇表（例如，一个 `vocab.json` 文件）。微调时，你的数据中的基因需要与此词汇表对齐。
- **数据集划分**:
    - 将数据集划分为训练集 (train)、验证集 (validation) 和测试集 (test)。这对于模型训练、超参数调整和最终性能评估至关重要。常见的比例有70/15/15或80/10/10。
    - 划分时应注意分层抽样 (stratified sampling)，尤其是在细胞类型不均衡或存在多批次数据时，以确保每个子集都能代表原始数据的分布。

## 2. 数据处理 (Data Processing)
此阶段的目标是将准备好的原始数据转换为模型可以直接输入的格式。
- **基因过滤 (Gene Filtering)**:
    - **与词汇表对齐**: 只保留数据集中那些存在于预训练模型基因词汇表中的基因。
    - **低表达基因**: 过滤掉在所有细胞中几乎不表达或表达量极低的基因。
- **细胞过滤 (Cell Filtering)**:
    - **低质量细胞**: 移除表达基因数量过少或文库大小过小的细胞，这些通常被认为是低质量细胞。
    - **稀有细胞类型**: 对于分类任务，如果某些细胞类型的细胞数量过少，可能需要考虑合并或移除，以避免模型难以学习。
- **数据标准化/归一化 (Normalization)**:
    - **库大小标准化**: 例如，将每个细胞的总计数标准化到特定值（如每万个计数，CP10k/CPM）。常用方法如 `sc.pp.normalize_total`。
    - **对数转换**: 对标准化后的数据进行对数转换（如 `log(X+1)`），以稳定方差并使数据更接近正态分布。常用方法如 `sc.pp.log1p`。
- **输入序列构建 (Tokenization and Input Formatting)**:
    - **基因ID映射**: 将基因名称映射为整数ID。这通常通过预训练时定义的`GeneVocab`完成。
    - **特殊标记 (Special Tokens)**:
        - `<cls>` (Classification Token): 通常在序列开头添加，其最终的隐藏状态向量被用作整个细胞的表征，用于下游分类任务。
        - `<pad>` (Padding Token): 由于每个细胞表达的基因数量不同，需要将基因序列填充到统一的最大长度 (`max_seq_len`)。
    - **细胞表示**: 每个细胞被表示为其表达基因的ID序列和对应的表达值序列。
        - `gene_ids`: 整数ID张量。
        - `values`: 对应的表达值张量。
    - **填充掩码 (Padding Mask / Attention Mask)**: 生成一个布尔张量 (`src_key_padding_mask`)，用于指示哪些是填充的基因，以便在注意力计算中忽略它们。
- **标签编码 (Label Encoding)**:
    - 对于分类任务（如细胞类型注释），将文本格式的细胞标签转换为整数编码。

## 3. 定义模型/参数 (Define Model/Parameters)
此阶段涉及加载预训练的scGPT模型并根据特定任务进行调整，同时设置微调所需的超参数

- **加载预训练模型**:
    - 实例化scGPT模型架构，例如 `scgpt.model.TransformerModel`。
    - 加载预训练好的模型权重 。
- **任务特定头部 (Task-Specific Head)**:
    - 对于大多数微调任务，需要在预训练模型的顶层添加一个新的模块，称为“任务头”。
    - **分类任务 (如细胞注释)**: 通常是一个线性层 (`nn.Linear`)，它将 `<cls>` 标记的输出嵌入（或其他细胞级表征）投影到类别数量上。输出维度等于细胞类型的数量。
    - **回归任务**: 头部可能是一个或多个线性层，输出一个或多个连续值。
    - **其他任务**: 根据具体任务设计头部结构。
- **冻结与解冻层 (Freezing/Unfreezing Layers)**:
    - 可以选择冻结预训练模型的部分或全部底层参数，只训练任务头和顶部的少数几层。这在训练数据较少时可以防止过拟合。
    - 也可以选择解冻所有层，让整个模型参与微调，这在有充足数据时可能获得更好性能。
- **超参数设置 (Hyperparameters)**:
    - **学习率 (Learning Rate)**: 控制模型参数更新的步长，通常需要为微调设置一个较小的值（如1e-4, 1e-5）。
    - **批次大小 (Batch Size)**: 每次迭代中用于训练的样本数量。
    - **训练轮次 (Epochs)**: 整个训练数据集通过模型的次数。
    - **优化器 (Optimizer)**: 如 AdamW，常用于Transformer模型。
    - **权重衰减 (Weight Decay)**: 一种正则化技术，防止过拟合。
    - **学习率调度器 (Learning Rate Scheduler)**: 例如，warmup后线性衰减，可以在训练过程中动态调整学习率。

### 4. 微调 (Fine-tuning)
此阶段是实际的模型训练过程。
- **损失函数 (Loss Function)**:
    - 根据具体任务选择。
        - **分类任务**: 交叉熵损失 (`nn.CrossEntropyLoss`)。
        - **回归任务**: 均方误差损失 (`nn.MSELoss`)。
- **优化器 (Optimizer)**:
    - 实例化所选的优化器，并将模型中需要训练的参数传递给它。
- **训练循环 (Training Loop)**:
    1. 将模型设置为训练模式 (`model.train()`)。
    2. 遍历训练轮次 (epochs)。
    3. 在每个轮次中，遍历训练数据加载器 (dataloader) 的批次。
    4. 对于每个批次：
	    1. 将数据移动到计算设备 (CPU/GPU)
	    2. **前向传播 (Forward Pass)**: 将批次数据（如 `gene_ids`, `values`, `src_key_padding_mask`）输入模型，获得输出（如分类任务的 `logits`）。 
	    3. **计算损失 (Loss Calculation)**: 使用损失函数计算模型输出与真实标签之间的差异。 
	    4. **反向传播 (Backward Pass)**: `loss.backward()` 计算损失相对于模型参数的梯度。
	    5. **参数更新 (Optimizer Step)**: `optimizer.step()` 根据梯度更新模型参数。 
	    6. **梯度清零 (Zero Gradients)**: `optimizer.zero_grad()` 清除梯度，为下一次迭代做准备。
- **验证 (Validation)**:
    - 在每个训练轮次结束后（或每隔N个步骤），在验证集上评估模型性能。
    - 将模型设置为评估模式 (`model.eval()`)，此时不计算梯度。
    - 计算验证损失和相关评估指标（如准确率）。
    - 根据验证集上的性能（如最低验证损失或最高验证准确率）保存最佳模型。这有助于防止过拟合，并选择泛化能力最好的模型。

## 5. 结果评估 (Results Evaluation)
在微调完成后，使用测试集评估最终模型的性能。
- **评估指标 (Metrics)**:
    - **分类任务**:
        - 准确率 (Accuracy)
        - 精确率 (Precision)、召回率 (Recall)、F1分数 (F1-Score)，特别是对于类别不平衡的数据集（可计算宏平均 Macro-F1 或加权平均 Weighted-F1）。
        - 混淆矩阵 (Confusion Matrix): 可视化各类别的分类情况。
        - ROC曲线和AUC值。
    - **回归任务**:
        - 均方误差 (MSE)、均方根误差 (RMSE)
        - 平均绝对误差 (MAE)
        - R² (决定系数)
    - **其他任务**: 根据具体任务选择，例如聚类任务的调整兰德指数 (ARI)、归一化互信息 (NMI) 等。
- **在测试集上评估**:
    - 加载表现最佳的微调模型。
    - 将模型设置为评估模式 (`model.eval()`)。
    - 在测试集上进行预测并计算所选的评估指标。测试集上的结果是衡量模型泛化能力的最终标准。
- **结果解释与可视化**:
    - 解释评估结果，分析模型的优势和不足。
    - 使用UMAP/t-SNE等可视化方法展示细胞嵌入，观察微调后的模型是否能更好地区分不同细胞类型或状态。
